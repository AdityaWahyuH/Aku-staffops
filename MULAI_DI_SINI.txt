AKU STAFFOPS - KODE SUMBER LARAVEL 13
===================================

1. INSTAL PHP 8.3+, COMPOSER, MYSQL (MIS. LARAGON), DAN VS CODE.
2. BUAT PROYEK LARAVEL BARU:
   composer create-project laravel/laravel aku-staffops "^13.0"
3. MASUK KE FOLDER aku-staffops DI VS CODE.
4. SALIN SELURUH FILE DARI PAKET INI KE DALAM PROYEK LARAVEL
   DENGAN STRUKTUR FOLDER SAMA (FILE YANG SAMA BOLEH DITIMPA).
   JANGAN HAPUS FILE BAWAAN LARAVEL LAINNYA.
5. BUAT DATABASE MYSQL aku_staffops.
6. EDIT FILE .env MENGIKUTI CONTOH DI README.md.
7. JALANKAN DI TERMINAL:
   php artisan key:generate
   php artisan migrate --seed
   php artisan serve
8. BUKA http://127.0.0.1:8000/login
